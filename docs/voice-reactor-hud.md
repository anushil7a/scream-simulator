# Voice-reactive bottom-center HUD

Editable Figma design is shared separately.

Reference inputs reviewed from the approved-concepts/UI vault: UI-03 Battle Burst Anime Fighter, UI-04 Neon Synth Audio Studio, UI-05 Coastal Slate Tactical HUD. Slate/gold housing and restrained cyan/violet signal accents are adapted, not imported as flattened mockups. Enemy health in reference images is deliberately excluded. Figma contains editable six-state compositions, bound palette variables, and auto-layout state rows. Montserrat is the design counterpart to existing Roblox Gotham.

`VoiceReactor.luau` owns passive geometry and tokens. `Client.client.luau` retains all existing capture/control/state semantics. The 28 bars represent recent normalized amplitude samples, not frequency bands or decibels. Sampling is bounded to one insertion per 40ms; the latest actual input goes at the right. Zero input drains the bank to a quiet baseline. The existing instantaneous meter and voice-onset threshold remain. Both game reduced effects and platform reduced motion replace scrolling history with a stationary amplitude bank. No pulse, glow oscillation, sound recording claim, input events, remote traffic, new persistence, or uploaded image assets.

Desktop: 300x96 on wide screens, otherwise 230x84. Phone: 230x84 below the reserved action controls. Narrow desktop: above the action controls. Below 315px viewport height, decorative meter hides rather than cover navigation. Existing TALK coordinates remain unchanged; desktop TALK and overlapping notices take priority over passive reactor art. Existing own-player health remains. Targeted player and resident HUD labels show name, level where applicable, and status, never enemy HP numbers. World-space nameplates are outside this change.

Validation: `tests/verify_local.py --build` passes 25 pure/synthetic and 140 mocked-service suites, production compilation, and local review builds. `voice_reactor.py` adds 83 mocked UI/amplitude/layout checks and source integration checks. Exact startup mocks include both new dependency boundaries. Figma board screenshot inspected after final edits. This is not live Roblox microphone, native rendering, font-fit, phone/device, or multiplayer proof. Next native check: quiet/rising/attacking/cooldown/disarmed/unavailable states at 390x844, 844x390, 1280x720; normal and reduced-motion; notice/TALK collisions; compare live normalized input with bar response.
