# Boss audio: source design and guarded runtime fallbacks

## Themes / ownership

Ten original synthesized 24kHz mono16-bit WAVs in `assets/audio/bosses`, generated by `tools/make_boss_audio.py` (stdlib, deterministic, no recordings/downloads). Each of five bosses has separate warning and actual-impact envelope. Metronome ticks; Golem rounded stone/bass; Ignis organ/fire; stable ID `leviathan` is **Seagull Siren Captain**, maritime horn/cutlass rather than a sea creature; Conductor harmonic bells. Alternate attack serials use modest6% pitch variation. Generation check confirms peak<=.46, |DC|<.00001 and silent endpoints, not listening quality.

Actual vault notes reviewed via reference research: Combat Sound Design and Feedback; Sound Design Pitfalls - Reused Ids Onsets and Layered Loops; sound-cue-audition. Followed distinct tell/impact, visual twins, warning priority, spectral/envelope identity instead of loudness and per-source caps. Existing beam audio/mix notes and source inspected. Authored attack timing/damage is unchanged.

## What can play now

**Original WAVs are not uploaded and cannot be shared-game SoundIds directly.** BossAudioConfig leaves custom AssetIds empty. Approved upload and destination experience permission are required to enable them. Assign each source file to matching two pattern variant cue IDs; uploaded originals use authored pitch1/1.06 rather than fallback tuning.

Fallback paths were inventoried in the official installed Studio `content/sounds` directory (November16), not guessed asset IDs:

- `volume_slider.ogg`: clock/conductor warning or bell-like placeholder.
- `action_jump_land.mp3`: clock impact.
- `action_get_up.mp3`: Golem/Captain warning placeholder.
- `impact_explosion_03.mp3`: Golem/Ignis impact.
- `action_jump.mp3`: Ignis warning placeholder.
- `impact_water.mp3`: Captain impact placeholder.

These are **generic packaged substitutes**, not the original bespoke organ/horn/bell cues. File existence is verified; decoded listening, native playback, current/mobile packaging and destination availability are **unverified**. Adapter requires PreloadAsync Success before allocating a Sound; unavailable assets stay silent. Six unique fallback paths are preloaded once each, at most3 attempts/path. No loads occur in the attack loop. No creator-store purchases, audio uploads or external action performed.

## Runtime / safety

Independent BossAttackAudio client script consumes BossAttackSerial/At plus BossAttackImpactSerial/At supplied by server actual attack resolution. Windup is the exact production state name. Initial streaming state never replays history; repeated serials deduplicate; split attribute delivery retries briefly; impact freshness is capped.25s. Removed/replaced source cancels its emitters; aborted tell cancels warning; polling/one-shot bounds prevent spam. Visual reduced-effects does not mute useful audio.

Four active voices share total Sound.Volume.08 under group.5 (nominal aggregate.04 before EQ/distance). Speaking or unknown microphone readiness ducks to25%; no-device spectators remain audible at that conservative level. Quiet/voice calibration suppresses all boss cues. These ceilings are not measured SPL or feedback prevention. Warnings replace a decorative impact when full, never another warning. Range70, near8; anchors noncollidable/nontouchable/nonqueryable. One-shots expire within1.15s, mute/character loss/script teardown clean them. Original camera/microphone/voice transport remains untouched.

Existing GAMEPLAY SFX LOW/OFF now accurately labels the shared mute rather than claiming all cues pending. Its extra info distinguishes packaged boss fallbacks and pending custom gameplay cues. Local-only preference attributes change only when their values change. Existing four-cue not-ready suppression remains unchanged; boss spectator policy is separate.
